# 🎓 مفقوداتي الجامعية | College Lost & Found System

نظام إلكتروني تفاعلي متكامل لإدارة وبلاغات المفقودات والمعثورات في الكليات والقاعات الجامعية، مصمم ومتوافق للعمل بسلاسة على أجهزة الآيفون (iOS)، الأندرويد (Android)، وأجهزة الكمبيوتر (Desktop).

---

## 🌟 أبرز المميزات

1. **📱 تجربة متوافقة مع جميع الأجهزة (Responsive & Multi-Device):**
   - واجهة مخصصة بالكامل لشاشات الهواتف الذكية (آيفون وأندرويد) مع شريط تنقل سفلي مرن.
   - وضع محاكاة شاشة الهاتف (Phone Simulator) لمعاينة تجربة المستخدم على الآيفون والأندرويد مباشرة من المتصفح.
   - واجهة عريضة مخصصة لأجهزة الكمبيوتر والمكتبي (Desktop).

2. **🔐 نظام تسجيل الدخول وإنشاء الحسابات:**
   - تسجيل الدخول بالرقم الجامعي أو البريد الإلكتروني.
   - إنشاء حساب طالب جامعي جديد.
   - ملف شخصي يحتوي على بطاقة هوية جامعية رقمية وسجل البلاغات الخاصة.
   - دعم حسابات خاصة بالأمن والسلامة لمتابعة وتسليم المفقودات.

3. **🏛️ تخصيص وتحديد أماكن القاعات والمباني بدقة:**
   - تحديد المبنى الجامعي (الهندسة والحاسب، إدارة الأعمال، السنة التحضيرية، المكتبة المركزية...).
   - تحديد الدور / الطابق.
   - تحديد رقم واسم القاعة (مثل قاعة 202، قاعة 101، معمل الحاسب...).
   - وصف الموقع الدقيق داخل القاعة (الصف، المنصة، بجوار النوافذ...).
   - توثيق مكان العثور على الغرض ومكان تسليمه ومراجعته للاستلام.

4. **📦 تصنيفات شاملة للمفقودات:**
   - جوالات وأجهزة ذكية (آيفون، أندرويد، شواحن، سماعات).
   - محافظ وحقائب.
   - بطاقات جامعية وهوية وبطاقات بنكية.
   - أجهزة لابتوب وآيباد.
   - مفاتيح وميداليات.
   - كتب ومستلزمات دراسية ونظارات وساعات.

5. **💬 نظام المحادثة والتواصل الفوري:**
   - شات مباشر داخل البلاغ لمتابعة حالة الغرض بين الطالب والأمن أو الشخص الذي وجده.
   - دعم الاتصال المباشر ورابط الواتساب بنقرة واحدة.
   - تنبيهات وإشعارات صوتية فورية.

---

## 🚀 كيفية التشغيل

المشروع مبني ليعمل مباشرة وبكل سهولة:

1. **التشغيل المباشر:**
   - قم بفتح ملف `index.html` في أي متصفح (Chrome, Safari, Edge, Firefox).
   - سيعمل التطبيق بكافة مميزاته وتفاعلاته بدون الحاجة لتثبيت أي حزم خارجية.

2. **التشغيل عبر بيئة تطوير Vite (اختياري):**
   ```bash
   npm install
   npm run dev
   ```

## 🛠️ التقنيات المستخدمة

- **React 18** - واجهة المستخدم التفاعلية وإدارة الحالة.
- **Tailwind CSS** - تصميم عصري بنمط Glassmorphism وألوان متناسقة.
- **Lucide Icons** - أيقونات واضحة وتفاعلية.
- **Web Audio API** - مؤثرات وتنبيهات صوتية مدمجة.
- **LocalStorage API** - حفظ واسترجاع بيانات المستخدمين والبلاغات محلياً.
